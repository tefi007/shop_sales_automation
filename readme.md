# Автоматизация обработки кассовых выгрузок

Проект эмулирует ежедневный поток данных из кассового софта торговой сети
(товары для дома) и автоматизирует их загрузку в базу PostgreSQL.

## Что делает проект

1. `generate_data.py` — генерирует csv-выгрузки касс в папку `data/`
   (имя файла: `номер_магазина_номер_кассы.csv`, например `11_2.csv`).
   Запускается по расписанию **каждый день, кроме воскресенья**.
2. `setup_db.py` — один раз создаёт базу `shop_sales` и таблицу `sales`
   (DDL — в `sql/create_tables.sql`).
3. `load_to_db.py` — забирает файлы из `data/` и загружает их в базу.
   Файлы, не подходящие под шаблон `{{shop}}_{{cash}}.csv`, игнорируются.
   Обработанные файлы переносятся в `data/processed/`, повторный импорт
   не создаёт дублей. Запускается **каждый день**.

## Структура репозитория

```
config.py            # настройки подключения к PostgreSQL
generate_data.py     # генератор ежедневных выгрузок
setup_db.py          # создание базы и таблиц (один раз)
load_to_db.py        # загрузка выгрузок в базу
sql/create_tables.sql  # DDL-команды
data/                # пример сгенерированной выгрузки
img/                 # скриншоты автоматизации и таблиц БД
```

## Как запустить на новой машине

1. Установить Python 3.11+ и PostgreSQL 14+.
2. Клонировать репозиторий и перейти в его папку.
3. Установить зависимости:
   ```
   pip install -r requirements.txt
   ```
4. В `config.py` указать хост, порт, пользователя и пароль PostgreSQL.
5. Создать базу и таблицы:
   ```
   python setup_db.py
   ```
6. Сгенерировать пример выгрузки и загрузить её в базу:
   ```
   python generate_data.py
   python load_to_db.py
   ```
7. Настроить расписание (ниже).

## Автоматизация через планировщик Windows

Созданы две задачи (скриншот — в папке `img/`):

- **shop_sales_generate** — генерация выгрузок, пн–сб в 08:00;
- **shop_sales_load** — загрузка в базу, ежедневно в 09:00.

Скриншоты в папке `img/`:

- `01_scheduler_summary.png` — обе задачи в планировщике;
- `02_task_generate_details.png` — расписание и действие генерации;
- `03_task_load_details.png` — расписание и действие загрузки;
- `04_db_tables.png` — таблица sales в базе shop_sales.

Команды для создания задач вручную (из cmd от имени того же пользователя):

```
schtasks /create /tn shop_sales_generate /tr "\"C:\путь\к\python.exe\" \"C:\путь\к\проекту\generate_data.py\"" /sc weekly /d MON,TUE,WED,THU,FRI,SAT /st 08:00
schtasks /create /tn shop_sales_load /tr "\"C:\путь\к\python.exe\" \"C:\путь\к\проекту\load_to_db.py\"" /sc daily /st 09:00
```

Проверить задачи: `schtasks /query /tn shop_sales_generate`.

## Формат выгрузки

`doc_id` — идентификатор чека, `item` — товар, `category` — категория,
`amount` — количество, `price` — цена позиции без скидки,
`discount` — сумма скидки на позицию (может быть 0).
В одном чеке несколько строк с разными товарами.
